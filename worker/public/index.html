SlopChecker screens grant proposals for fabricated citations, misquoted sources, and AI-generation signals, then puts the evidence beside the passage it refers to. Built for funding-org reviewers drowning in machine-written submissions.

How to read a result

NO

Failed a verifiable check

The DOI didn't resolve. The quote isn't in the paper. You can check it yourself without trusting this tool.

YES

Passed a verifiable check

The reference exists and its metadata matches. Passing isn't an endorsement of the argument, only of the citation.

0.96

A score, not a verdict

Detector and similarity scores render in their own lane. They are context for a human reviewer, never grounds for rejection.

How it works

1 · Upload

PDF, DOCX, Markdown, or HTML. The document is flattened to plain text with its page structure kept for anchoring.

2 · Checks run

Cheap deterministic checks first: DOI resolution, metadata match, quote verification, section compliance. Detector scores where keys are configured. A check that can't run reports as skipped, never silently.

3 · Evidence report

One self-contained page — every finding highlighted in the document with its evidence beside it, plus a full check ledger. Exportable to PDF. See a sample.

SlopChecker is a screening aid, not a determination. It recommends passages for human review; it never auto-rejects. Boolean findings are independently verifiable. Scores are probabilistic and never sufficient on their own.
