# 2026-07-31 — 990991A / Alex (Claude Opus 4.8) — Synthetic proposal fixtures + eval harness

**Issues worked:** #22.

## What changed

- `scripts/synth/synth_proposals.py` — generator for a labeled corpus of
  synthetic grant proposals. Dimensions → tuples → generate (Hamel & Shreya's
  evals method): authorship (human / ai_clean / ai_laundered / slop) ×
  institution_tier (Carnegie R1/R2) × discipline × applicant_type × defect.
  Two backends: `template` (stdlib-only, deterministic, committable) and
  `anthropic` (Messages API over urllib, no SDK — realistic prose). Human
  seeds come from tier-stratified NIH RePORTER pulls, or fabricated under
  `--offline`. Emits corpus.jsonl + manifest.csv + coverage.json.
- `scripts/synth/score.py` — eval harness. Reads manifest.csv (ground truth) +
  a check's predictions, reports precision/recall/F1/accuracy per defect.
  `--demo` runs a naive baseline.
- `tests/fixtures/synthetic/` — committed offline corpus (60 docs, fully
  fabricated, seed 42) + README mapping ground truth to the report.json checks.
- `tests/fixtures/README.md` — fixtures index (satisfies the #22 README ask).

## Decisions

- **Committed set is `--offline` (fully fabricated), never the NIH-seeded mode.**
  Keeps us inside #22's "no real applicant material, ever." NIH-seeded mode is
  for local eval only.
- **Tooling in `scripts/`, data in `tests/fixtures/`.** CI runs
  `ruff format --check src tests` but not `scripts/`, and the CI note says not to
  reformat `scripts/` as a side effect — so the generator/scorer stay lint-clean
  (`ruff check .` passes) without being pulled into the formatter's scope.
- **urllib, not the `anthropic` SDK.** No new dependency; the `[llm]` extra isn't
  required to generate or score. Falls back to template on any API error.
- **Ground truth as boolean columns**, matching the "checks are true|false|number,
  no LLM prose in the evidence layer" decision. `score.py` consumes them directly.

## Dead ends / caveats

- Naive baseline in `score.py` scores ~1.00 on the template corpus but drops to
  0.00 recall on budget_inflated / missing_methods against a model-backed corpus
  — a check that only passes on templates hasn't been tested against real slop.
  That gap is the reason the corpus exists; left the demo honest rather than
  tuning it to look good.
