## Decisions / dead ends

- **PDF hangs on exit, so don't wait for exit.** macOS Chrome (and CI chromium,
  the #47/#49 crashpad deadlock) writes the PDF but never returns from
  `subprocess.run(..., capture_output=True)`. `--headless=new` + DEVNULL streams
  + `--disable-crash-reporter/--disable-breakpad` did NOT fix the mac hang.
  Fix that worked: `Popen`, poll until the PDF file size stops growing, then
  `terminate()` the browser. The committed PDF is the artifact; a clean browser
  exit isn't required.
- **PDF is a local build step, never CI.** MD/HTML/DOCX are reproducible
  anywhere; PDF needs a browser and is intentionally out of the CI path.

## Validation (the point of the task)

lost in print→extract), `media_type=application/pdf`, `pages=2`. That PDF
structure gap is a real characteristic worth a check/test.
