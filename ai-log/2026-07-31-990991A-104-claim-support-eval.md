## Issue

#104: build a small labeled corpus and score the claim-support check (#11).
Depends on #11 (closed) and PR #100 (merged today). Both satisfied before start.

## What landed

- `harness/claim_support_corpus.yaml` — 20 fabricated (claim, source, verdict)
  triples, 4 per verdict category. Every person/finding/citation invented, per
  CLAUDE.md. Ground-truth labelling rules documented in the file header,
  mirroring the judge system prompt (esp. the unsupported vs unverifiable line).
- `harness/claim_support_eval.py` — driver. Loads the corpus, runs the **judge
  stage** per triple against a real `AnthropicTransport`, and reports a 5×5
  confusion matrix, per-category precision/recall/F1, a `min_confidence`
  threshold sweep, and a misclassification list. Writes `--markdown`/`--json`.
- `harness/claim_support_fixtures/` — a fabricated proposal + keyed source files
  for the end-to-end **silence check**: runs the full `ClaimSupportCheck.run`
  over supported/unverifiable claims and asserts zero findings surface.
- `harness/results/claim_support_eval_2026-07-31.md` + `.json` — the run snapshot
  posted to #11.

## Key decision (recorded on #104/#11)

The confusion matrix scores the **judge stage**, not the full check. The full
check collapses to binary (finding vs silence) — the five verdict categories
only exist before run() silences supported/unverifiable/low-confidence. So the
harness calls `ClaimSupportCheck._judge` directly (real prompt/schema/transport/
parse), which is the only place a 5-way verdict is observable. The silence pass
covers the end-to-end behavior separately.

## Results (20 triples, claude-opus-5 judge)

- Overall judge accuracy **85%** (17/20).
- 4/4 correct on supported, unsupported, contradicted, unverifiable.
- Only error mode: 3/4 `overstated` → `contradicted`. All three are claims that
  are directionally right but assert a specific quantity/category the source
  refutes ("eliminated", "doubled", "safe autonomously"). Fuzzy boundary; both
  are concern verdicts, so the finding still surfaces — only the severity note
  changes. No operational miss, no false accusation.
- **Zero false alarms** at every threshold: the judge never flagged a clean
  claim as a concern. No evidence to move `min_confidence` off the arbitrary
  0.6 default → recommend keep 0.6, re-test on a larger corpus.
- Passage quotecheck: 9/12 concern verdicts carried a `match_quote`-clean
  passage (the other 3 would be dropped before the report).
- End-to-end silence check: PASS.
