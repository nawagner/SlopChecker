## What changed

- `scripts/synth/synth_proposals.py` — `--near-dups N` appends N near-duplicate
  clones after the main corpus. Each clone is a light paraphrase (`_launder`) of
  a random existing record, flagged `is_near_duplicate=true` with
  `duplicate_of` pointing at its original. New ground-truth `is_near_duplicate`
  (default False on every normal record) and meta `duplicate_of`; both added to
  `manifest.csv`; `near_dups` recorded in `run_meta.json`.
- `scripts/synth/score.py` — scores `is_near_duplicate`; the naive baseline
  predicts False (cross-document similarity can't be seen from one doc's text).
- `tests/fixtures/synthetic/` — corpus regenerated to 126 (120 + 6 clones).
- README updated; near-duplicate removed from open items.

## Decisions

- **A relational property, not a `defect` value.** A near-dup is defined by its
  relationship to another record, so it lives outside the per-doc defect axis:
  a separate `--near-dups` phase after the dimension grid, and a boolean +
  `duplicate_of` pointer rather than a `defect` enum member.
- **Clone label inherits the original's**; the near-dup signal is the flag, not
  the authorship. Text is paraphrased (not identical) so it's *near*, not exact.
- **Not added to `files/`** — near-dup is a corpus-level similarity property,
  best tested across the corpus, not on a single rendered file. First 120 records
  are byte-identical to before (clones append after), so committed files are
  unchanged.
